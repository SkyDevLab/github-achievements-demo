# Pair Extraordinaire Demonstration

This file and its commit demonstrate co-authoring commits using Git trailers.

### Git Trailer Format
```git
Co-authored-by: The Octocat <583231+octocat@users.noreply.github.com>
```

When this commit is merged into `main` via a Pull Request, GitHub credits both authors with the collaboration and qualifies for the **Pair Extraordinaire** profile achievement badge.
