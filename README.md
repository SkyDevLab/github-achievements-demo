## 🛠️ Step-by-Step Breakdown of Performed Workflows

### 1. ⚡ Quickdraw
* **Condition:** Close an issue or pull request within 5 minutes of opening it.
* **Demonstrated:** Created Issue [#1](https://github.com/SkyDevLab/github-achievements-demo/issues/1) via GitHub CLI and closed it immediately.

### 2. 👥 Pair Extraordinaire
* **Condition:** Co-author a commit that gets merged into the default branch (`main`) via a Pull Request.
* **Format Used:**
  ```git
  git commit -m "Add Pair Extraordinaire collaboration feature" -m "Co-authored-by: The Octocat <583231+octocat@users.noreply.github.com>"
  ```
* **Demonstrated:** Merged in [PR #2](https://github.com/SkyDevLab/github-achievements-demo/pull/2).

### 3. 🚀 YOLO
* **Condition:** Merge a pull request without an approving code review.
* **Demonstrated:** Created branch `yolo-feature`, committed `YOLO.md`, opened [PR #3](https://github.com/SkyDevLab/github-achievements-demo/pull/3), and merged it straight away.
